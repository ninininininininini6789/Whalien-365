## Pomodorobypanini
Hi!!!! Welcome to my first coding project, a pomodoro timer with an active to-do list, which enables you to add and remove tasks, which I've named, Pomodorobypanini

view here: https://ninininininininini6789.github.io/Whalien-365/frontpage.html

### All the whys and hows
Personally, when I'm studying, I love to use apps like Forest and pomodoro websites to keep track of my studying, as well as keep track of my to-dos, however, I've always felt that my tasks and my study time was separated, making it harder to keep track of what I did each day. Hence, I decided to make my own website where I can keep track of both!!

This is my first ever coding project and because of that, I was very nervous on what to code, which coding languages to use and so on so forth, and I went on a deepdive through the internet to figure out how to code different types of pomodoro timers, with different aesthetics and colours. I was a bit concerned that a pomodoro timer may be too hard for my first time, however, as there were many tutorials for pomodoro timers, there were much less for the type of to-do list which I wanted to code. Additionally, as this was my first time coding, I needed to learn how to code Javscript, html, and css coding for web development and how to add my own touch to it. In the end, I found some very helpful tutorials which I edited to make my own aesthetic!!

I hope you have fun with my website!!
